Milk Run Scheduler

Local-only scheduling tool. Paste Dump data, generate the run, and export it. Nothing is uploaded.

1. Paste Dump data

Copy the Dump table from Excel or your source system, click below, and paste with Ctrl+V / Cmd+V.

2. Configuration

VenueContactTypeStops/dayTruck AMTruck PMVan order

Stops/day = 1 marks a one-stop venue. Truck AM/PM and Van order control stop sequence; blank or 0 excludes a venue from that ordered list.
